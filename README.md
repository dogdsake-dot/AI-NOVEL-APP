# AI-NOVEL-APP

Android/mobile port of [ExplosiveCoderflome/AI-Novel-Writing-Assistant](https://github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant).

This repository vendors the upstream AGPL-3.0-only source and keeps the original long-form novel production stack intact wherever practical. Mobile-specific changes are isolated in the mobile wrapper and small compatibility patches.

> Bootstrap in progress: the repository workflow will synchronize the upstream source, apply the Android port overlay, build an installable APK, and publish a GitHub Release.
